# WhyStock 기획서

## 1. 문제 정의

개인 투자자는 종목이 급등하거나 급락했을 때 가격, 뉴스, 공시, 거래량 정보를 각각 따로 확인해야 한다. 정보는 많지만 이유를 빠르게 정리하기 어렵고, 단순한 예측형 AI는 신뢰도가 낮다.

## 2. 서비스 정의

WhyStock은 급등락한 종목의 변동 이벤트를 기준으로 관련 뉴스, 공시, 거래량 변화를 모아 AI가 원인과 근거를 구조화해주는 웹 서비스다.

핵심 문장:

> 주가 변동의 이유를 1분 안에 이해하게 해주는 AI

## 3. 핵심 사용자

- 주식 뉴스 해석이 어려운 초보 투자자
- 관심 종목의 급등락 이유를 빠르게 확인하고 싶은 사용자
- 투자 결정을 AI에게 맡기기보다 근거를 정리해 보고 싶은 사용자

## 4. MVP 범위

### 메인 기능

- 급등/급락 이벤트 목록
- 이벤트별 가격 변화, 거래량 변화, 관련 뉴스/공시 표시
- AI 기반 이유 3개 요약
- 각 이유별 근거 출처 연결
- 조건 기반 시나리오 제시

### 보조 기능

- 경제 용어 설명
- 관련 종목 연결
- 분석 결과 캐싱

### 제외 기능

- 매수/매도 추천
- 수익률 예측
- 자동매매
- 사용자 계좌 연동

## 5. 차별화 포인트

일반적인 "AI 주식 추천 서비스"가 아니라, 가격 변동의 원인을 설명하는 "이유 중심 AI"로 범위를 좁혔다. 또한 AI의 답변이 단독으로 존재하지 않고 기사/공시/시장 반응에 연결되도록 설계했다.

## 6. 시스템 구조

```text
React/Vite 또는 정적 SPA
        |
Backend API
        |
Market Event Scanner
        |
Data Collector
  - price
  - news
  - disclosure
        |
AI Reason Analyzer
        |
SQLite/PostgreSQL
```

이번 MVP는 의존성 없이 실행되도록 Python 표준 라이브러리 기반 서버와 정적 SPA로 구현했다. 이후 확장 시 FastAPI, React, PostgreSQL로 옮기기 쉽도록 API 경계를 유지했다.

## 7. 데이터 설계

핵심 엔티티는 `stock`이 아니라 `movement_event`다.

- `stocks`: 종목 기본 정보
- `movement_events`: 특정 시간대의 급등락 이벤트
- `sources`: 뉴스, 공시, 가격 데이터 등 근거 자료
- `analyses`: AI 분석 결과
- `related_stocks`: 관련 종목과 연결 이유

## 8. AI 분석 원칙

AI는 다음 원칙을 따른다.

- 원인은 최대 3개
- 반드시 제공된 근거에서만 도출
- 각 원인에는 근거 source id 포함
- 예측 대신 조건 기반 시나리오 제시
- 투자 추천으로 오해되지 않도록 고지

## 9. 발표 포인트

> 단순히 LLM을 호출한 것이 아니라, 비정형 금융 정보를 구조화하고 각 원인을 근거 출처와 연결해 설명 가능한 AI 결과를 만들었습니다.

강조할 기술 요소:

- 비정형 데이터 구조화
- JSON 기반 AI 출력 제어
- 설명 가능한 AI
- 이벤트 중심 데이터 모델링
- 예측 회피와 조건 기반 시나리오

## 10. 확장 계획

- OpenDART 공시 API 연동

- 분석 결과 히스토리 비교
